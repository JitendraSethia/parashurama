# From prototype to product

## 1. Prove it with real users (0–6 months)
- Bring on a **domain advisor** (e.g. a retired air-defence officer) to validate doctrine, threats and weapon behaviour.
- **Pilot** with one unit or training school (DSSC after SIH), free or low-cost.
- **Measure** detection time, identification accuracy and mistakes before vs after. This data sells the product.
- Fix what users report: Hindi, realism, laptop performance, more threat types.

## 2. Harden for military use
- **Air-gapped updates:** signed offline update and threat-pack files installed from USB.
- **Windows installer** with code signing (most service laptops run Windows).
- **Security:** VAPT by a CERT-In empanelled auditor, SBOM, secure development process.
- **No classified data in the product:** units load their own values.
- **Scale:** multi-unit / command level, optional Postgres, VR later.
- **Engineering:** split and strictly type the UI, accessibility, full regression suite.

## 3. Company and IP
- Register a company (or use Marvex Solutions); get **DPIIT startup recognition**.
- **Trademark search** for "PARASHURAMA" before filing (name is used by an IAF vintage aircraft).
- Software copyright; ask an IP attorney about any patentable method (pure software is hard to patent in India). Get proper legal advice.

## 4. How customers buy

| Route | Buyer | Notes |
|---|---|---|
| SIH → ministry interest | MoD / DSSC | Opens doors; not a purchase order |
| iDEX | Armed forces | MoD startup innovation scheme; best fit |
| DRDO TDF | DRDO | Funds technology development with industry |
| Make-II (DAP) | Armed forces | Industry-funded prototype, path to orders |
| GeM | Police, CISF, BSF, PSUs | Faster for smaller purchases |
| Hardware partners | Anti-drone system makers | Bundle as their training module (we are vendor-neutral) |
| Private / critical infrastructure | Airports, refineries, ports | Faster sales cycle |

Defence buying often takes 1–3 years; police, PSU and partner sales can come sooner.

**Business model:** annual licence per unit or seat + threat-pack subscription + training and support; free or low-cost pilot to get in.

## Timeline
- **0–3 months:** advisor, field-ready build (installer, signed offline updates, Hindi), security audit started, company and trademark.
- **3–6 months:** pilot with 1–2 units, iterate, collect results.
- **6–12 months:** apply via iDEX / Make-II, list on GeM, first police / PSU / partner customer.
- **12–24 months:** multi-unit rollout, VR, more threat packs, partner bundles.

**Team:** domain advisor, 2–3 engineers, security/QA, one person who knows defence procurement.
